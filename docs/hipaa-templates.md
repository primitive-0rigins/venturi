maintainers do not complete these records for a customer.

## System inventory and data flow

Record the Venturi host, shelf/database paths, dashboard host, IdP, TLS proxy,
model endpoint, backup destination, administrator, network paths, and whether
each system creates, receives, maintains, or transmits ePHI. Attach a current
diagram with trust boundaries and data classifications.
